# Протокол UART, версия 1

Скорость: 57600 бит/с, 8N1. Кадр ASCII имеет вид
`$<поля через |>*<CRC16-CCITT-FALSE в верхнем регистре>\n`. CRC считается по
телу, начальное значение `FFFF`, полином `1021`; тестовый вектор
`123456789 → 29B1`. Максимум кадра — 192 байта. Порядковый номер `id` —
десятичное 1…65535; у самостоятельных сообщений стенда используется 0.

| Запрос | Ответ |
| --- | --- |
| `id|PING` | `id|PONG|1` |
| `id|GET` | `id|STATE|YYYY-MM-DD|HH:MM:SS|weekday|status|valid|errors|oled|rx_overflow|uart_errors` |
| `id|SET|YYYY-MM-DD|HH:MM:SS|weekday` | после записи `id|OK|SET`, затем `0|STATE|…` |

`weekday`: 1…7 (понедельник…воскресенье), задаётся независимо от календарной
даты. `status`: `STOPPED`, `RUNNING`, `STARTING` или `ERROR`; `valid=0` требует
нулевых даты/времени `0000-00-00`, `00:00:00`. Битовая маска `errors`:
1 — I²C, 2 — BCD/дата, 4 — генератор, 8 — PWRFAIL, 16 — ошибка записи.
Ошибки команды: `CRC`, `FRAME`, `FORMAT`, `VALUE`, `BUSY`, `I2C`, `RTC_WRITE`,
`COMMAND`, `TIMEOUT`.

Клиент записывает каждую порцию и каждый распознанный кадр в JSONL с UTC-меткой
времени, направлением, hex-представлением и текстом. Поэтому двоичные/ошибочные
данные также сохраняются без потери.
