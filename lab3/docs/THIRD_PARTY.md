# Сторонние компоненты

- STM32CubeF4 HAL/CMSIS — файлы в `Drivers/`, STMicroelectronics; лицензии
  сохранены рядом с исходными файлами.
- `pyserial` 3.5 — зависимость клиентской программы, устанавливается из
  `client/requirements.txt`.
- Unicorn — используется только в локальном тестовом окружении и не входит в
  прошивку или клиент.

Шрифт SSD1306 в `Core/Src/gfx.c` записан вручную в исходном коде проекта.
