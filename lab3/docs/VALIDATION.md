# Валидация

## Проверка на стенде 09.11.2026

- Через встроенный FTDI/JTAG обнаружен STM32F42x/43x; прошивка
  `build/lab3/lab3.elf` записана и проверена OpenOCD (`Verified OK`).
- На COM8 при 57600 8N1 стенд ответил на PING сообщением PONG и передал STATE.
- Изначально RTC сообщал STOPPED. После SET с датой и временем компьютера
  получено OK, состояние перешло в RUNNING, показания секунд увеличивались.
- В ответе STATE состояние OLED — 1, ошибок RTC и UART нет. Это подтверждает
  успешные обращения к дисплею по данным прошивки, но изображение глазами
  не проверялось. Проверку визуального вида экрана следует выполнить на стенде.
