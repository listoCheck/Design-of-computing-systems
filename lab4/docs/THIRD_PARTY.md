# Использованные компоненты

`Core` и `Drivers` основаны на проекте `lab3` этого репозитория. Клиент PC
используется непосредственно из `lab3/client`.

FreeRTOS Kernel V10.0.1 (файлы `FreeRTOS/Source`, порт GCC ARM_CM4F и heap_4)
взят из официального примера производителя стенда
[SDK_FreeRTOS](https://github.com/lmtspbru/SDK-1.1M/tree/master/SDK_FreeRTOS).
Его исходники содержат текст лицензии MIT в заголовках. Библиотеки ST/CMSIS
сохранены со своими файлами лицензий в `Drivers`.
