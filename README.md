# Проектирование вычислительных систем

Лабораторные работы для стенда SDK-1.1M (STM32F427):

- [Лабораторная № 1 — GPIO, «Светофор»](lab1/README.md).
- [Лабораторная № 2 — UART, «Светофор»](lab2/README.md): HAL и собственный
  регистровый драйвер, режимы прерываний и опроса, команды, эхо, тесты без платы.
- [Лабораторная № 3 — OLED-дисплей и устройства I²C, «Часы»](lab3/README.md):
  MCP79411, SSD1306, GUI-клиент UART, журнал и TIM6 для планирования обновления.

Сборка и проверки лабораторной № 2 из корня репозитория:

```powershell
python lab2/tools/build.py
python lab2/tests/run_tests.py
```

Для этих команд микроконтроллер подключать не нужно. Инструкции запуска на стенде,
отчёты и ограничения проверок находятся в папках соответствующих работ.

Сборка и проверки лабораторной № 3:

```powershell
python lab3/tools/build.py
python lab3/tests/run_tests.py
```
